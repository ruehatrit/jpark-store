เชื่อมเครื่อง ZKTeco THAI01

เครื่อง: 10.10.33.201 : 4370

  1. ดาวน์โหลดโปรแกรมแล้วแตก ZIP บนคอมที่เชื่อมถึงเครื่องสแกน
  2. สร้างไฟล์ config.json และย้ายไปในโฟลเดอร์เดียวกับ START_LIVE.cmd
  3. เปิด START_LIVE.cmd รอ READ OK / uploaded แล้วกลับดูหน้าเว็บ
  4. ต้องการทำงานเบื้องหลัง ให้ปิดหน้าต่างตัวกลางด้วย Ctrl+C แล้วเปิด INSTALL_BACKGROUND.cmd
ดาวน์โหลดโปรแกรมตัวกลาง

การสร้างไฟล์ตั้งค่าใหม่ยกเลิกคีย์เก่า ถ้าเปลี่ยนคีย์ให้หยุดตัวกลาง เปลี่ยน config.json แล้วเปิดใหม่ ไม่ต้องใส่รหัสแอดมินเว็บในตัวกลาง

คอมต้องเปิดและเชื่อมเครือข่าย โปรแกรมเริ่มเบื้องหลังหลังผู้ใช้คนนี้เข้าวินโดวส์ เป้าหมายอ่านทุก 5 วินาที ระยะจริงขึ้นกับเครื่องและอินเทอร์เน็ต การส่งประวัติครั้งแรกอาจใช้เวลานานกว่า

เก็บ config.json เฉพาะบนคอมตัวกลาง ห้ามอัปโหลดเข้า GitHub หรือโฟลเดอร์เว็บไซต์
